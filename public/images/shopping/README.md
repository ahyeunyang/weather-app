# 쇼핑 이미지

쇼핑 탭의 대표 상품과 큐레이션 이미지를 보관합니다.

- `eat-sunny-sky.png`: `먹으러` 탭 대표 비주얼의 하늘 배경. 화면에서 실제 `weather-logo-black-fixed-v2.svg`를 CSS 마스크로 적용합니다.
- `eat-mango-bingsu.png`: `먹으러` 탭 망고 빙수의 원본 RGB 이미지입니다. 원본 비교용으로 보관하며 화면에서는 직접 사용하지 않습니다.
- `eat-mango-bingsu-transparent.png`: `먹으러` 탭의 망고 빙수 대표 상품. 배경을 제거한 투명 알파 PNG이며 로고 마스크 오른쪽 아래에 별도 레이어로 겹칩니다.
- `buy-orange-tshirt.png`: `사러` 탭 대표 상품의 원본 RGB 이미지입니다. 원본 비교용으로 보관하며 화면에서는 직접 사용하지 않습니다.
- `buy-orange-tshirt-transparent.png`: `사러` 탭의 대표 상품. 오렌지 반소매 티셔츠만 남긴 투명 알파 PNG이며 화면에는 이 파일을 사용합니다.

화면에서는 `/images/shopping/파일명`으로 참조합니다. 원본 이미지의 저작권과 상업적 사용 권한을 확인한 뒤 배포합니다.
