# 캐릭터 에셋

앱 전역에서 사용하는 캐릭터 에셋은 캐릭터별 영문 소문자 폴더에 보관합니다.

- `jjaengi/`: 쨍이
- `mongi/`: 몽이
- `bomi/`: 보미
- `popo/`: 포포
- `puri/`: 푸리

현재 연결된 에셋:

- `puri/puri-bingsu.svg`: 쇼핑 광고에 사용하는 빙수를 든 푸리 캐릭터

파일명은 영문 소문자와 하이픈을 사용하며, 화면에서는 `/characters/캐릭터명/파일명` 경로로 참조합니다. 캐릭터 전용 포즈와 표정은 해당 캐릭터 폴더에 함께 관리하고 특정 페이지 이미지 폴더에 중복 저장하지 않습니다.
